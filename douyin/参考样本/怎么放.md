# 参考样本放这里

## 放什么

把你想对标的抖音书单视频放进来，**文件夹名用「账号名」，里面放截图 + 文字**：

```
参考样本/
  账号A_读心术/- 
    视频1_标题.txt      ← 这条视频的标题、话题、文案原文（能抄到就抄）
    视频1_封面.jpg      ← 封面截图
    视频1_开头.jpg      ← 前 3 秒那一帧
    视频1_数据.txt      ← 点赞/评论/收藏（能看到就写）
  账号B_某某读书/
    ...
```

## 最低要求

- **3 个账号 × 各 3 条**，就能调出可用的规律（钩子句式、结构、时长）
- 已经有播放数据的**自己的视频**最有价值：好的 3 条 + 扑的 3 条
- 拿不到文案原文没关系，截图我也能读

## 我会做什么

1. 拆出钩子句式 → 归纳成可复用模板
2. 数时长、数每句停留、看字幕断行 → 反推节奏参数
3. 看封面配色/字号/构图 → 改 `cards.py` 和 `config.json`
4. 结论写进 `爆款手册.md`，此后每条视频自动按规则生成

## 快速方式（懒人版）

不想整理文件也行，直接把视频链接或截图发我，说一句"对标这条"，我来拆。
