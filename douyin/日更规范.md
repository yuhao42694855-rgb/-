## 一、固定项（账号识别度，每天都不许变）

用户两次强调「一定要是我发那个视频的表达方式，别错了」——以下七项对齐参考片《停止内耗》：

1. 顶部常驻书名 + 作者
2. 黑白去色画面 + 唯一一处亮橙
3. 一屏一句，3–5 秒一换
4. 中英双行，中文随口播**逐字渐显**（不是卡拉OK高亮）
5. 片头立体书封悬浮
6. 片尾搜索条卡
7. 9:16 / 28–35 秒 / 30fps（完播甜点区），另出 3:4 发布封面

合规四件套也不能变：全自写文案并标注「读书感悟 · 非原文摘录」、选公版或已核实的书、自有素材 + SIL OFL 开源字体、AI 显式 + 隐式标识。

## 二、每天必须换的变量（**防同质化，这是平台红线**）

抖音官方明确：批量生产的套路化内容挤压认真创作者空间，已有账号健康分和十类营销号违规治理。**固定表达方式可以，只换书名的机械量产不行**。每天至少换掉 3 个变量：

| 变量 | 取值范围 | 规则 |
|---|---|---|
| 钩子类型 | 反常识 / 身份点名 / 痛点直击 / 数字冲击 | 四型轮换，不与前一天同型 |
| 钩子句 | `hook_line`（两行大字）+ `hook`（口播首句） | 18–28 字，不说「今天分享」，直接进内容 |
| 书目 | **优先追当下热门书**，公版古籍只作保底 | 多源核实热度/作者/版本；不重复 `queue/` 里做过的 |
| 主视觉意象 | 3 张自有剪影轮换 + 裁切/暖光位置变化 | 不连续两天同一张主视觉 |
| 片尾提问 | 5–12 字，具体可回答 | 不重复前一条；首评给 A/B/C 选项 |
| `save_line` | 片尾「截图保存 · + 一个具体动作」 | 不重复前一条；呼应首评，给收藏理由 |
| 六句文案 + 英文 | 全自写、人工校译 | 不冒充原文 |
| 封面大字 | = 当条钩子，不是书名 | 书名已常驻顶部，封面别再重复 |

`python scripts/daily.py --next` 会给出下一条该用的钩子类型和已做过的书目；`daily.py 任务.json` 会强制校验 `save_line` 等字段齐全。

## 三、前 3 秒怎么写（能不能吸引住眼球，全在这）

- **首屏信息层级**：钩子大字 > 书名 > 书封。片头两行钩子大字放在书名下方、书封上方，白色宋体 **66px**（2026-11-12 由 58px 加大），长句自动缩字号防溢出。
- **四型模板**

| 类型 | 骨架 | 例句 |
|---|---|---|
| 反常识 | 否定一个大家默认的说法 | 「越想静下来，越静不下来，问题不在你不够努力」 |
| 身份点名 | 把人群钉死 | 「写给 30 岁还在硬撑的人」 |
| 痛点直击 | 第二人称说破没说出口的感受 | 「你不是想太多，是没人教过你怎么放下」 |
| 数字冲击 | 具体数字 + 悬念 | 「一生被贬三次，最后一年他还在往回走」 |

- **禁忌**：不说「大家好」「今天给大家分享」、不先报书名、不用陈述事实开场、不用「治愈/治好」这类效果承诺。
- **首尾闭环**：钩子埋的问题，片尾提问要接回来。
- **封面 = 钩子**：3:4 封面的大字用同一句钩子，别换成书名；搜索结果缩略图里能读到的一句，决定点不点开。

**三次升级（2026-11-14，用户拿参考号例子对比后说「清晰度不够，和这个比很差」）**：

| 根因 | 改动 |
|---|---|
| **静态卡被放大 2 倍再缩回来**：`image_segment` 把 1080×1920 卡片先 scale 到 2160×3840，再由 zoompan 缩回，烘焙在图里的字与书封被重采样两次，这是「字发虚」首因 | `compose.image_segment` 新增 `still` 直出分支（`motion=False` 时零缩放、`-loop 1` 静态帧） |
| 遮罩写成三段**阶跃**，y=420 / y=1180 出现两道横向硬边，画面像被切开 | 改分段线性插值，全程平滑；主体区几乎不压（轮廓清楚），只压书名区 / 字幕区 / 底部 |
| 遮罩语义写反过一次：`Image.composite(a, b, mask)` 是 mask=255 取 a（黑），v 是「叠黑比例」不是亮度 | 已按正确语义定值，别再改回去 |
| 1024 源图放大发虚 | `UnsharpMask(1.2, 140, 2)` + `Contrast 1.12` |
| 两段编码 crf16 / medium，成片 1.4–1.9 Mbps | **crf12 / slow / tune stillimage**，给抖音二次压缩留余量 |
| 正文用无衬线黑体，气质平、边缘钝 | ASS 字幕改 `Noto Serif SC` 82px、描边 2、字距 2（字体本身是 700Bold，ASS `Bold` 必须设 0，否则粗得发糊） |
| 中文与英文相隔约 320px，散；且**英文一度跑到中文上方**——中文逐字渐显时行数会变，卡片里写死的英文 y 跟不上 | 英文改为 **`Style: En` 独立 Dialogue + `\pos(540,1550)\an2` 绝对定位**，整句期间常显、顺序永不颠倒；英文改短句意译，≤48 字符保证单行 |
| 放进中文 `\N` 第二行时英文**整句都不显示** | 中文用 `\k` 卡拉OK，libass 会把后面无 `\k` 的文本排进同一音节队列，要等整句念完才出现；`\k0` / `\r` / `\1c` 都救不了，**必须独立字幕轨**（已用纯色底隔离渲染验证） |
| 片头底偏亮，白钩子压不住 | 片头额外叠 30% 黑，回到参考片的近纯黑开场 |
| 封面因底图提亮白字可能糊 | 封面叠 38% 暗罩 |
| 中文长句被排成 3 行，逐字渐显时第三行尚未显形，中英间距在 **86–254px** 之间跳动 | `build_reveal_ass` 断行改为「按句长对半 `brk=seg_len//2`、**渲染后再判断断点**（标点留在上一行末尾）、最多断一次」，每行 ≤11 字；Sub 的 MarginL/R 90→50。**关键**：中文 Sub 也必须 `{\pos(540,1450)\an2}` 绝对定位——只靠 `Alignment=2 + MarginV` 时成片里中文块会被整体上移约 168px，英文轨因用 `\pos` 不受影响。双 pos 后实测长短三句间距 88 / 86 / 86px |
| `daily.py` 标着「出片前自检」却硬检查封面已存在，导致每条新任务首次自检必然误报失败 | 成片文件存在才硬检查封面；未出片时只打印提示 |

> 参考号「陌言读书」的例子只有 720×960 / 200 kb/s 却看着清晰，原因是**纯黑底 + 高对比白字 + 静态画面 + 真实照片的锐利轮廓**，不是低码率的功劳。我们背景是带纹理的 AI 图，只能靠高码率源片 + 免重采样 + 主体提亮来追。完整拆解见 `爆款案例库.md` 第 9 节。

出片后抽帧自检：放大到 100% 看字边缘、**看画面有没有横向硬边**、**至少抽 2 句长短不同的正文，确认中英间距一致**、看右下角无残字、看切点无黑帧、看片头片尾左下角 AI 标识、看时长落在 28–35 秒。

**文案长度上限**：每句中文 ≤ 22 字（含标点）。超过就可能被断成 3 行，重新引入中英间距跳动；`daily.py` 的 28–35 秒甜点区也要一起看。

## 五、AI 标识：角标能去掉，标识不能省

用户要求去掉左上角常驻角标。查《人工智能生成合成内容标识办法》第四条第四项原文：视频**起始画面**和播放周边「应当」加显著标识，末尾/中间「**可以**」加（可选）。所以：

- **正文屏左上角角标：已去掉**（属可选，不构成隐匿标识，画面更干净）
- **片头 + 片尾：保留显著的「AI 生成内容」标识**，放左下角（左缘 x=84，与底部声明对齐），不占顶部书名区
- **文件元数据**隐式 AIGC 字段保留
- **投稿页「自主声明」必须勾**：入口已前置到投稿一级页面，首次漏标教育、多次限流
- 平台会按第六条自行在「发布内容周边」补显式标识，那一处我们控制不了，画面角落可能仍会看到平台加的提示
- **尺寸下限（2026-11-12 定，仍有效）**：片头/片尾与封面统一为 28px 字、白底黑字细胶囊、左下角。**28px 是下限，不能再缩，也不能改成低对比灰字**——那就是"小字隐蔽标注"，反而违规
- **位置（2026-11-14 用户看参考片后要求「放左下角最下面」）**：视频标识 y **H-340 → H-140**，底部声明整体上移 66px（线 `H-280`）腾出独立一行；封面**维持 1130**（1:1 安全区下沿 1260 是硬限制，试过 1180 会与底部声明挤在一起）
- ⚠️ 贴到最底部后，**抖音底部标题栏/进度条可能压住这一带**。所以「投稿页主动声明 AI 生成」从建议升级为**必做兜底**：画面标识 + 文件元数据 + 平台声明，三者缺一不可
- 用户看到参考片「左下角最下面那行小字」其实是 `@陌言读书 / 内容来自书评 / 感悟` 和抖音号**水印**，不是 AI 提示；参考片通篇没有 AI 标识，那是对方的合规缺口，不能学
- 禁止用小字、遮挡、模糊表述做隐蔽标注（属违规）

## 六、每天的出片流水线

1. 你给**一个书名**（或一句情绪，我来选书）
2. 我实时核实作者 / 版本 / 内容 / **当下热度**，查 `queue/` 避重复
3. 按轮换定钩子类型 → 写 `hook_line` / `hook` / 6 句 / 英文 / 片尾提问 / `save_line`
4. 写 `queue/verse-xxx.json`（含 `hook_type`、`cover_sub`、`save_line`、`bg_offset`、`_日更变量`）
5. `python scripts/daily.py --next` 看轮换
6. `python scripts/cover.py queue/verse-xxx.json` 生成 3:4 封面 + 1:1 预览（自检会查封面是否存在，必须先跑）
7. `python scripts/daily.py queue/verse-xxx.json` 自检，全绿再出片
8. `python scripts/verse.py queue/verse-xxx.json` 出片
9. 抽帧验清晰度、右下角无残字、片头片尾 AI 标识、切点无黑帧、时长
10. 附发布包：标题 / 话题 / 简介 / 首评 / AI 声明
11. **发布后 7 天不删、不隐藏、不二次编辑**，第 1 / 3 / 7 天回填 `数据记录.csv`

## 七、发布节奏与数据

- **每天 1 条**，不多号同发、不刷量、不组织集中点赞；早期反馈要真实
- 别为了等「黄金档」压稿：官方明确发布时间不影响分发
- **7 天长效赛马**：冷启动 500–1000 曝光，考核周期已从 24h 拉到 7 天，很多视频第 5–6 天才靠收藏量起量；删稿重发属同质化，会打断长尾推流
- **收藏率是第一权重**（第三方 2026 口径）：收藏率 > 复访率 > 铁粉互动 > 5 秒完播 > 整体完播 > 点赞 > 转发；及格 3%、爆款 5%、低于 2% 难破万播放。回填后算「收藏 / 播放」
- **搜索是第二条增长曲线**：日均搜索 PV 约 41 亿，搜索带来播放占比 30%+；标题、字幕、口播都要带书名 / 作者 / 核心词
- 情绪疗愈型主看**收藏 + 评论 + 搜索来源**，不要只用完播率判生死
- 每周复盘一次：哪种钩子类型 / 意象 / 书类最能留住人，写回手册

> 以上权重、及格线、7 天赛马来自第三方运营监测，**不是抖音官方口径**，只当假设；用我们自己的 `数据记录.csv` 做 A/B 验证后再定论。

### 10.1 A 档默认规则（版式零改动，不改任何锁定项）

写 `verses` 时逐条对照：

| # | 规则 | 自检 |
|---|---|---|
| 1 | 正文由 6 句长叙事改 **12–15 屏短句**，每屏 **6–14 字**，至少 3 屏 ≤8 字，短长交替；**总字数 140–160 字** | 句长方差要看得出来；字数不够会掉出甜点区 |
| 2 | 至少 **3 句第二人称 / 普遍断言**；以「他 / 书中人物」作主语的不超过 1 句 | 观众是当事人不是旁观者 |
| 3 | 至少 **1 组跨屏拆句**：前半句故意不说完，下一屏接上 | 参考片「上天 → 必先打磨你 → 磨到你不再纠结」 |
| 4 | 至少 **1 句 1221 / 1213 句式**：不是 A 是 B、反义词对撞、重新定义 | 参考片「放下也是为了放过自己」 |
| 5 | **最后一句必须短、能单独截图**；`save_line` 与片尾提问呼应它 | 金句不能只出现在末尾一句 |
| 6 | 用具体动作/物件替代抽象词：不说「很犹豫」，说「再等等」「先在心里过三遍」 | 禁「内耗 / 焦虑 / 治愈」这类概括词 |
| 7 | 全自写、不引在版书原文或译文；英文同步改成短句意译 | 合规底线不动 |

**表达方式七件套仍一项不许改**：顶部书名作者 / 黑白+橙 / 一屏一句 / 中英双行 / 逐字渐显 / 立体书封 / 片尾搜索条。

⚠️ **字数≈时长**（历史实测 139/145/155 字 → 28.9/30.6/31.5 秒，约 5 字/秒）。金句化后每屏只有 6–14 字，**只写 8 屏约 100 字会掉到 21–26 秒**，所以必须 12–15 屏、总 140–160 字（2026-11-14 备《自控力》时修正；四个方向实测 29.2–30.0 秒）。出片后按 `work/<id>/meta.json` 复核；不足就补 1–2 屏留白短句，**不要靠把句子拉长补**。

### 10.2 B 档（**需用户明确同意才可执行**）

加 1 屏 2 字超大词卡 + 1 屏留白、一句跨两屏、画面 2–3 屏换一次意象。会动「一屏一句」锁定项和 `verse.py` 的屏数逻辑；**没得到明确同意不要动代码**。
